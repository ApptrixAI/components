# Apptrix Chat Widget

Simple chat interface with an easy API for quick integration, that only requires
two methods on the message source, and returns a basic message format.
With a defined callback the input field and send button are enabled, and when
submitted, the function is called with the text as argument to send a message.

## Example

To run example chat application with random messsages:
```
cd example
go mod tidy
go run example_*.go
```
